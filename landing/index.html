TeX Notary v0.x

A focused LaTeX workspace that feels fast, local, and yours.

TeX Notary gives you unlimited projects, version snapshots, Markdown preview, and one-click PDF compile in a desktop-first workflow.

Download Releases View Source

  • Monaco LaTeX Editor

    Snippets, outline jumps, and keyboard-first flow.

  • Snapshot Timeline

    Save, restore, and keep project history local in SQLite.

  • Responsive Markdown Preview

    Pandoc-backed preview while you edit.

  • Desktop Packaging

    macOS, Windows, and Linux artifacts via GitHub Actions.
